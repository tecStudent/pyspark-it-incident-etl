# v1.0.0 — Operational PySpark Incident ETL

Primeira release estável do pipeline local de Engenharia de Dados para incidentes de TI, construído com PySpark, Apache Spark 4.1.2 e Docker.

## Destaques

- arquitetura medalhão Raw, Bronze, Silver e Gold;
- carga completa e incremental idempotente;
- Data Quality com quarentena e reconciliação entre camadas;
- regras auditáveis de KPI e OLA;
- agregações, ranking de risco, previsão explicável e recomendações;
- contratos JSON e manifesto com verificação de integridade;
- dashboard operacional publicado gratuitamente no GitHub Pages;
- tendências particionadas e carregadas sob demanda;
- Web Vitals locais, sem cookies ou telemetria externa;
- testes, cobertura, smoke test e CI com GitHub Actions;
- benchmark Spark reproduzível e perfil otimizado;
- governança de contribuição e licença MIT.

## Executar localmente

~~~bash
git clone https://github.com/tecStudent/pyspark-it-incident-etl.git
cd pyspark-it-incident-etl
git checkout v1.0.0
docker compose build
docker compose run --rm spark python3 -m pytest -q
~~~

As instruções completas de execução estão no README.

## Dashboard

[Abrir o dashboard operacional](https://tecstudent.github.io/pyspark-it-incident-etl/)

O GitHub Pages publica somente dados analíticos agregados. O arquivo acadêmico original, os Parquets e os controles locais não fazem parte da release.

## Limitações conhecidas

- execução local, sem orquestrador distribuído;
- controles incrementais baseados em JSON local, sem locking distribuído;
- snapshots Parquet sem formato transacional;
- previsão baseada em baseline estatística, não em modelo de machine learning;
- recomendações determinísticas de apoio à decisão.
